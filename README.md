# Kola & Ember Café ☕🍃

A modern, responsive basic website designed for **Kola & Ember Café**, a premium conceptual coffee shop based in Colombo. This project showcases the café's aesthetic, menu offerings, and brand identity through a clean user interface.

## ✨ Features

* **Premium Aesthetic:** Minimalist design reflecting a modern Colombo coffee house.
* **Responsive Layout:** Optimized for seamless viewing on desktops, tablets, and mobile devices.
* **Interactive Menu:** Easily browsable sections for specialty brews, local infusions, and pastries.
* **Contact & Location:** Clear operational hours and location details.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (or specify frameworks if using React/Tailwind)
* **Fonts & Icons:** Google Fonts, FontAwesome

## 🚀 Getting Started

To run this project locally, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/HAMYL-Aththnayaka/kola-ember.git](https://github.com/HAMYL-Aththnayaka/kola-ember.git)

```

2. **Navigate into the project directory:**
```bash
cd kola-ember

```


3. **Open the project:**
* Open `index.html` directly in your preferred browser, or use the **Live Server** extension in VS Code.
*Or Follow the  Original Site here -- https://web-builder.42web.io/index.html *
